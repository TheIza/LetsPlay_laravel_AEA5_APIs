# LetsPlay - AEA5

Proyecto académico de desarrollo de una aplicación web para la gestión y reproducción de partidas mediante una API desarrollada con Laravel.

---

## Descripción

LetsPlay es una aplicación que permite gestionar partidas, usuarios y diferentes funcionalidades relacionadas con el sistema de juego a través de una API REST.

El proyecto ha sido desarrollado como parte de la actividad AEA5, utilizando Laravel y una arquitectura basada en APIs.
